## 实现方案

### 方案一：生成单独音频文件（❌ 不可行）

**原因：** 系统无法安装 ffmpeg 或其他音频处理工具
- `ffmpeg` - 未安装，且无法通过 apt 安装（需要 sudo 密码）
- `sox` - 未安装
- Node.js 音频混合库 - 配置复杂，需要多个依赖

### 方案二：用 JavaScript 同时播放（✅ 已实现）

**状态：** 已完成

**实现方式：**
1. 在 `agents-dashboard.html` 页面添加"齐声问好"按钮
2. 点击按钮后，同时触发 10 个 audio 元素播放
3. 所有音频音量降至 50% 避免混音失真
4. 添加 20ms 微小 stagger 避免浏览器阻止多个自动播放

**修改文件：**
- `/home/richard_chin/.openclaw/workspace/agents-dashboard.html`

**新增功能：**
- 新增"齐声问好"按钮（🙇 图标）
- 新增 `playGreetingAll()` 函数
- 新增 `stopGreetingAll()` 函数

## 使用方法

1. 打开 `agents-dashboard.html` 网页
2. 点击右上角的"齐声问好"按钮（紫色，🙇图标）
3. 10 个 Agent 会同时播放问好音频
4. 再次点击按钮可停止播放
